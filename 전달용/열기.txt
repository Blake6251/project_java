COSTOOL 전달용 웹사이트 (로컬 껍데기)
====================================

상대방 PC에서 보는 방법
1) 이 "전달용" 폴더 전체를 압축해서 전달하거나 USB로 복사
2) 받은 사람이 폴더 안의 index.html 을 더블클릭
3) 기본 웹브라우저(Chrome / Edge)로 열림

서버 설치 / Node / npm / 인터넷 연결 필요 없음.

포함 화면
- index.html        홈(랜딩)
- products.html     상품 카탈로그
- reservations.html 예약
- roadmap.html      개발현황
- login.html        로그인(데모)

로고: assets/logo.png (COSTOOL)

주의
- 실제 회원가입/결제/DB 저장은 동작하지 않는 UI 시연용입니다.
- "개발 진행 중" 배너가 의도적으로 표시됩니다.
